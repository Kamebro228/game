# Последняя ставка

Первый игровой 3D-прототип криминального триллера для ПК, Godot 4.6+.
Графика условная: крыша казино, оборудование, охранник и соседняя стройка.

## Запуск

Откройте `project.godot` в Godot 4 и нажмите F6/F5 либо выполните:

```sh
cd /workspace/game
godot --path . --editor
# Или сразу игра:
godot --path .
```

Зависимостей и внешних ресурсов нет. WASD — движение, мышь — камера,
Shift — бег, Ctrl — скрытность, пробел — прыжок, E — взаимодействие,
R — перезапуск, Esc — освободить курсор, щелчок — захватить снова.

Доберитесь до сервера в дальнем конце крыши, нажмите E и вернитесь
к жёлтой площадке эвакуации на соседней стройке. Охранник патрулирует
крышу: укрытия перекрывают обзор, скрытность уменьшает дальность обнаружения.
Полная шкала подозрения или падение завершают попытку.

Это основа для проверки игрового цикла. Лазание, бой, анимации,
озвучка, полноценный сюжет и сборка Windows пока не реализованы.

Проверка загрузки без графического окна:
`godot --headless --path . --quit-after 120`
